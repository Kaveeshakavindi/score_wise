# Custom Chatbot

A personal CLI chatbot built to experiment with LangChain, session handling, and a simple PostgreSQL-backed chat history. It provides a lightweight way to register users, start new chat sessions, and resume previous conversations.

## Purpose

This project is for learning and iterating on LangChain features in a practical app, while keeping the architecture small and easy to modify.

## Planned Improvements

I am planning to add more functions to progress in LangChain, by adding:

- Session titles auto-generated by LLM
- Vector memory per session
- Tool calling
- User-specific system prompts
- TUI (Rich / Textual)
- And way more
